### 更新摘要

- Web/API 为 OmniMail Float `0.7.0` 增加附件、同步、文件夹、草稿、发信和回复的来源级
  最小 Scope。
- 扩展授权页明确披露附件、文件夹、同步与用户主动提交的发信操作；旧设备令牌不会静默
  获得新增权限。

### 安全

- Float 仍不能读取或修改第三方凭据、连接/断开账号、删除邮件、下载原文或修改账号设置。
- 所有附件、同步和发信请求继续执行用户归属、工作区开关、大小限制、服务端租约、限速、
  幂等和审计检查。
- 新邮件通知只读取 OmniMail 与 Gmail、Microsoft、QQ、NAVER、Yandex 的服务端本地索引；
  不由浏览器按分钟触发 iCloud 或 Linux DO 远端 IMAP。

### 升级说明

- 无需 D1 迁移、新增变量、Secret 或资源绑定。
- Web/API `0.10.2` 可直接升级；未使用 Float 的部署不受影响。
- Web 版本为 `0.10.3`，Float 使用独立版本 `0.7.0`；本次不发布 Chrome Web Store 更新。

### 测试

- 通过设备 Scope、扩展授权、附件/发信现有服务端测试、TypeScript、Oxlint、完整单元测试、
  扩展生产构建和真实 Chromium smoke test。

### 发布

- Web 版本为 `0.10.3`；通过 GitHub Tag `v0.10.3` 发布，无额外 Web 下载文件。
- Float `0.7.0` 保持独立版本和安装包；本次不上传 Chrome Web Store。
