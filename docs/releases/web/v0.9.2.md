### 更新摘要

- 管理员操作日志新增独立的“QQ 邮箱”分类，便于快速定位账号连接、同步和发信问题。
- QQ 邮箱操作记录增加同步阶段、错误码、重试状态、邮件数量和耗时等安全化诊断详情。

### 新增

- 新增 `qq-mail` 审计分类，统一收纳 QQ 账号、发信身份、同步和发信事件。
- 新增手动同步请求、首次或手动同步成功、同步失败的审计事件。
- QQ 账号连接、重命名、授权码更新、验证、断开，以及发信身份创建和删除记录更完整的
  账号与身份信息。

### 改进

- 同步结果显示任务来源、尝试次数、同步阶段、错误码、是否重试、发现与拉取数量和耗时。
- 发信记录显示脱敏后的发件人、收件人、收件人数及新建或回复类型，不记录邮件内容。
- 操作日志可按 QQ 账号名称、身份名称和邮箱搜索；分类筛选栏在较窄窗口中自动换行。
- 定时同步只在错误码发生变化时记录失败事件，避免相同错误持续刷屏；定时成功不写审计日志。

### 安全

- 邮箱地址在写入和展示时脱敏，旧日志中的完整邮箱也会在界面展示前再次脱敏。
- 不记录授权码、密码、Token、邮件主题、正文、附件名称或 IMAP/SMTP 原始响应。

### 升级说明

- 本版本不包含新的 D1 数据库迁移。
- 本版本不需要新增或修改 Cloudflare Variables、Secrets 或资源绑定。
- 已部署 `0.9.1` 的实例可以直接升级；历史 QQ 操作会归入新分类，但新增诊断字段仅适用于
  升级后产生的事件。

### 测试

- 590 项 Web/Node 单元与组件测试、10 项 Worker 集成测试全部通过。
- Playwright 覆盖 QQ 邮箱分类请求、详细诊断字段和分类筛选栏响应式布局。
- TypeScript、Oxlint、生产构建和 Wrangler dry-run 通过。

### 发布

- Web 版本为 `0.9.2`；通过 GitHub Tag `v0.9.2` 发布，无额外 Web 下载文件。
- 本次 Web Release 不包含 OmniMail Float 扩展包或 Android 安装包。
