### 更新摘要

- 新增独立 Gmail 多账号聚合收件箱，并支持账号范围切换与元数据搜索。
- 正文和附件按需从 Gmail 读取，打开正文后会尝试同步 Gmail 已读状态。
- Gmail 应用专用密码加密保存在部署者自己的 D1 中，不保存邮件正文或附件。

### 新增

- 支持连接多个个人 Gmail 或 Google Workspace Gmail 账号，并执行连接验证、重命名、
  手动同步、应用密码更新和断开操作。
- “全部 Gmail”按时间聚合已连接账号的 INBOX 索引，也可切换到单账号范围。
- 支持搜索发件人、收件人、抄送和主题，并使用稳定游标继续分页。
- 支持按需读取 HTML/纯文本正文、最大 5 MiB 的单个附件，以及打开正文后写入受控的
  `\Seen` 已读状态。

### 改进

- 首次同步只索引最近 100 封 INBOX 元数据，之后每五分钟执行增量同步，每账号最多保留
  最近 500 封元数据。
- 固定宽 HTML 邮件会缩放到桌面或移动阅读区内，搜索和账号切换会取消过期请求。
- 单账号同步失败不会阻断其他 Gmail 账号，账号管理会显示可恢复的错误状态。
- Gmail 账号弹窗增加完整的遮罩淡入淡出与卡片位移动画，退出完成后再卸载，并兼容
  “减少动态效果”和键盘焦点圈定。

### 修复

- Gmail 元数据搜索改用 D1 兼容的字面子串查询，`%` 和 `_` 不会被当作通配符。
- 更新应用专用密码会撤销正在运行的旧同步租约，旧任务不能再把已恢复账号覆盖为凭据错误。
- 空阅读页文案与实际行为保持一致，明确说明打开邮件会尝试同步 Gmail 已读状态。
- 手动同步不再等待 Queue 发送完成才返回；Queue 延迟时由响应后任务和 Cron 补偿，避免
  双账号同步成功却在前端显示 15 秒连接超时。

### 安全

- 应用专用密码使用独立 `GMAIL_CREDENTIALS_KEY` 和 AES-GCM 加密，附加数据绑定用户、账号
  与凭据用途；API 和日志不返回密码、正文或敏感邮件内容。
- IMAP 主机、端口和 TLS 固定为 `imap.gmail.com:993`，不允许用户提供任意服务器或命令。
- 远端操作仅包含受控读取和精确的 `UID STORE ... +FLAGS.SILENT (\Seen)`；不支持归档、
  移动、删除、星标或发信。
- 凭据验证按用户与来源 IP 限速，并限制 IMAP 命令、响应、正文和附件大小。

### 升级说明

- 部署会应用 `0025_gmail_imap.sql` 和 `0026_gmail_unlimited_accounts.sql` 两个 D1 迁移。
- 使用 Gmail 功能前，在 Worker Variables & Secrets 中配置至少 32 字节且独立保存的
  `GMAIL_CREDENTIALS_KEY`，然后重新部署。
- 可将 `GMAIL_IMAP_ENABLED=false` 作为紧急开关；不配置 Gmail Secret 时功能保持禁用。
- 不使用 Gmail 的现有部署可以直接升级，无需连接账号或迁移邮件正文。

### 测试

- 通过 Gmail 凭据加密、用户隔离、IMAP 命令边界、MIME 解析、同步租约、D1 存储、搜索、
  已读与附件 API 的自动化测试。
- Playwright 覆盖账号连接、双账号聚合与范围切换、搜索、部分同步失败、分页、已读、附件、
  固定宽邮件和 375 px 响应式边界。
- 通过 TypeScript、文件行数限制、Worker 集成测试、Web 生产构建、发布元数据检查和
  Wrangler dry-run。
