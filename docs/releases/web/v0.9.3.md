### 更新摘要

- 修复 QQ 邮箱部分 `UID FETCH` 响应缺少 UID 导致首次同步失败的问题。
- 操作日志支持打开详情查看完整的诊断信息，不再只能看到截断后的摘要。

### 修复

- QQ 邮箱元数据同步改为逐 UID 请求；QQ 省略响应 UID 时使用当前请求 UID 安全关联。
- QQ 返回的 UID 与请求不一致时拒绝写入，避免把邮件元数据关联到错误邮件。
- 同步失败日志补充安全化的错误类型、错误说明和状态码，便于在 Workers Logs 与操作日志中
  定位问题。

### 改进

- 操作日志每行增加“查看详情”入口，弹窗展示时间、操作标识、操作者、目标、来源 IP、日志
  ID 和完整诊断字段。
- 详情弹窗支持键盘焦点管理、`Esc`/遮罩关闭、长文本换行和窄屏布局。

### 安全

- UID 关联不会使用 FETCH 响应中的消息序号作为 UID；邮箱地址继续脱敏。
- 日志不记录授权码、密码、Token、邮件主题、正文、附件名称、堆栈或服务器原始响应。

### 升级说明

- 本版本不包含新的 D1 数据库迁移。
- 本版本不需要新增或修改 Cloudflare Variables、Secrets 或资源绑定。
- 已部署 `0.9.2` 的实例可以直接升级。

### 测试

- 592 项 Web/Node 单元与组件测试、10 项 Worker 集成测试全部通过。
- 覆盖 QQ 缺少 UID 的 FETCH 响应、UID 错配保护、日志详情弹窗、键盘关闭和 375px 窄屏布局。
- TypeScript、Oxlint、生产构建和 Wrangler dry-run 通过。
