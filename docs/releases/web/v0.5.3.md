### 更新摘要

- 管理员打开邮箱首页时自动检查是否存在新版本，并用五秒后自动消失的轻量提示告知，
  不需要用户确认。
- iCloud 增加主邮箱模式，只配置邮箱地址和应用专用密码即可收信，不再强制要求 Cookie。
- 优化 iCloud、Linux DO 和 Gmail 的当前邮箱展示与复制操作，并完成 Web 与 Worker
  源码目录的模块化重组。

### 新增

- 管理员进入邮箱首页后自动调用版本检查；仅在存在更新时显示提示，检查失败不会干扰
  邮箱操作。
- iCloud 主邮箱加入收件地址列表，可单独筛选邮件并复制地址。
- 新增仅主邮箱配置方式：填写 iCloud 邮箱与应用专用密码即可完成连接，无需提供 Cookie。

### 改进

- Linux DO 邮箱标题增加当前邮箱地址和复制按钮；Gmail 增加当前账号邮箱复制按钮。
- 提高 iCloud 邮箱切换器中的账号名称、邮箱地址字号和文字对比度。
- iCloud Cookie 仅在同步、创建或管理隐藏邮箱时需要；未配置 Cookie 时跳过隐藏邮箱同步，
  并明确禁用相关操作。
- Web 前端按应用装配、业务功能和共享能力组织；Cloudflare Worker 按应用装配、业务功能、
  平台适配和共享能力组织。
- 拆分大型 Hono 路由、D1 Schema 与迁移定义、API 类型、国际化文本和响应式样式，并新增
  架构边界文档，降低后续维护和新增邮箱 Provider 的定位成本。

### 升级说明

- 无需新增 D1 迁移、Worker 变量、Secret 或资源绑定，现有 `v0.5.2` 部署可直接升级。
- Gmail、iCloud 和 Linux DO 的现有账号、凭据与邮件索引无需重新配置。
- 已有 iCloud 隐藏邮箱账号保持原有行为；只使用主邮箱的用户可以在账号设置中补充邮箱
  和应用专用密码。

### 测试

- 自动化测试覆盖版本检查、iCloud 主邮箱连接与地址筛选，以及外部邮箱标题和复制操作。
- 发布候选通过 Web、Worker、Playwright、浏览器扩展、TypeScript、代码检查、生产构建、
  发布元数据检查和 Wrangler dry-run。
