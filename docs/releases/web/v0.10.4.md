### 更新摘要

- Web 版本为 `0.10.4`，新增 iCloud（应用专用密码）与 Linux DO Mail 的轻量 IMAP 元数据索引。
- 新增统一 `/api/mail-notifications` 接口，供 Float 一次请求读取通知摘要。
- 使用已有 Queue 和 5 分钟 Cron 调度；不存储第三方邮件正文或附件。

### 升级说明

- 部署前应用 D1 迁移 `0035_external_mail_indexes.sql`。
- Float 使用独立版本 `0.8.0`；旧版令牌需要重新授权以获得新通知读取权限。
- iCloud Cookie-only 账号不参与后台索引，仍可从 Float 中手动打开收件箱。

### 测试

- 通过 TypeScript、Oxlint、单元测试和隔离 D1 全量迁移验证。

### 发布

- 本次不发布 Chrome Web Store 更新；待后续版本稳定后再发布商店。
