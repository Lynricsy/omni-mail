### 更新摘要

- 优化 Microsoft 账号管理弹窗的滚动范围，账号数量与管理操作始终保持可见。
- 单账号断开使用独立确认弹窗，避免确认区域挤压账号设置内容。
- 四类外部邮箱的邮件详情整列均可滚动，正文两侧空白区域也能直接响应滚轮。

### 改进

- Microsoft 账号卡片列表成为独立滚动容器，批量管理与添加账号按钮不再随列表滚动。
- 邮件正文继续保持最大宽度和居中布局，仅将外层详情列扩展为完整滚动区域。
- 账号管理与邮件详情滚动均保持原有响应式布局和键盘操作方式。

### 修复

- 修复 Microsoft 账号较多时顶部操作按钮被滚出弹窗的问题。
- 修复断开单个 Microsoft 账号时，确认区域被追加到设置页面底部的问题。
- 修复 iCloud、Linux DO、Gmail 和 Microsoft 邮件详情两侧空白区域无法滚动的问题。

### 升级说明

- 无需新增 D1 迁移、Worker 变量或 Secret；现有邮箱账号、凭据和邮件索引无需调整。

### 测试

- TypeScript、Oxlint、文件行数检查、组件测试、18 项相关 Playwright E2E 与生产构建通过。
- 已在 Cloudflare 线上环境人工验证账号弹窗和邮件详情滚动行为。

### 发布

- Web 版本为 `0.6.1`；通过 GitHub Tag `v0.6.1` 发布，无额外 Web 下载文件。
- 本次 Web Release 不包含 OmniMail Float 扩展包或 Android 安装包。
