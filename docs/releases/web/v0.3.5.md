### 更新摘要

- 收件箱新增“仅看未读”筛选和更清晰的未读状态提示。
- iCloud 隐藏邮箱批量创建、账号添加和状态展示获得完整体验优化。
- 中国大陆 iCloud 区域更新到 Apple 当前 Web 客户端参数，并补齐创建链路测试。

### 新增

- 未读筛选支持选中状态、无未读邮件空状态，以及对当前可见结果的批量选择。
- 未读邮件右侧增加与收藏星标同轴的状态点，同时保留字体强调和屏幕阅读器说明。
- 添加 iCloud 账号时可以同时填写可选的 iCloud 邮箱与应用专用密码；Cookie 与 IMAP
  凭据全部验证成功后才会原子保存。
- 新增中国大陆区域“验证账号 → 生成隐藏地址 → 保留地址”的完整请求回归测试。

### 改进

- 隐藏邮箱批量创建按钮更名为“增加邮箱”，新增卡片平滑进入；弹窗高度变化保持空间
  连续性，并遵循系统的减少动态效果设置。
- 隐藏邮箱卡片使用稳定的两列布局，增加第二个地址时不再改变已有卡片宽度。
- iCloud IMAP/Web 状态由整块提示卡压缩至右上角操作区，降低视觉干扰。
- iCloud 账号资格说明改为醒目的内联警示，并优化移动端应用密码表单。
- iCloud 区域选择由下拉菜单改为“全球 / 中国大陆”双段滑块，支持平滑滑动、键盘操作、
  可见焦点与减少动态效果。

### 修复与兼容

- iCloud Web 请求构建号更新为 Apple 当前的 `2630Build35`，修复中国区生成或保留隐藏
  邮箱时可能出现的 Apple HTTP 400。
- 全球区与中国区分别使用 `icloud.com` 和 `icloud.com.cn` 的 Origin、Referer、服务发现
  与 Hide My Email 服务域。
- iCloud Cookie 和应用专用密码继续使用 `ICLOUD_CREDENTIALS_KEY` 在 Worker 内加密，
  API 不会向浏览器回传原值。

### 升级说明

- 无需新增 D1 迁移、Worker 变量、Secret 或资源绑定，正常重新部署即可。
- 中国大陆账号请在添加时选择“中国大陆”，并从 `icloud.com.cn` 登录会话导出 Cookie。

### 测试

- 通过 80 个测试文件、370 项单元测试和 8 项 Worker 测试。
- 通过 58 项 Playwright 浏览器回归，覆盖 iCloud 工作区、批量隐藏邮箱、未读筛选和
  区域滑块。
- 通过 TypeScript、Worker 集成类型检查与 Web 生产构建。

### 发布

- Web 版本为 `0.3.5`；通过 GitHub Tag `v0.3.5` 发布，无额外 Web 下载文件。
- OmniMail Float 与 Android 继续使用独立版本号，本次不随 Web 版本升级。
