### 更新摘要

- 新增 Yandex Mail 只读 IMAP 工作区，可在 OmniMail 中集中管理多个个人 `@yandex.com` 邮箱。
- 支持有限 INBOX 索引、账号范围切换、元数据搜索、按需正文与附件读取，以及打开邮件后的
  精确远端已读同步。
- 功能默认关闭，由部署级环境开关和管理员入口开关共同控制。

### 新增

- 新增 Yandex Mail 账号连接、重命名、验证、应用密码更新、手动同步和断开 API。
- 新增 Yandex 邮件聚合列表、稳定游标分页、账号筛选、搜索、正文与附件接口，共 10 个端点。
- 新增独立 Web 工作区、统一二级账号管理弹窗、Yandex 图标、中英文文案和审计事件。
- 新增 D1 迁移 `0034_yandex_mail_imap.sql`，保存账号密文、有限邮件元数据和验证限速状态。
- 新增部署检查、管理员入口设置、设置指南、接入计划和完整 API Catalog 文档。

### 改进

- 首次同步最近 100 封；后续单轮最多拉取 20 封新增邮件并刷新最近 20 封状态。
- 每账号最多保留最近 500 封 INBOX 元数据，正文和附件按需读取，不写入 D1 或 R2。
- 默认每账号 15 分钟调度一次，使用 Queue、有限重试和带过期时间的同步租约。
- 账号管理弹窗打开期间自动刷新后台同步状态，关闭弹窗时同步刷新账号和邮件列表。

### 修复

- 修复 Yandex 同步任务已经完成、D1 状态已恢复为 `active`，账号管理弹窗却因状态快照过期而
  持续显示“正在同步”的问题。
- 修复关闭账号管理弹窗后立即打开邮件时，后台列表刷新可能用旧快照覆盖当前会话已读状态的
  竞态；已确认读过的邮件不会在本地刷新中退回未读。

### 安全

- 仅接受个人 `@yandex.com` 邮箱和 Yandex ID 中为“邮件”创建的应用密码，不接受账号主密码、
  企业自定义域名或共享邮箱技术用户名。
- 固定连接 `imap.yandex.com:993` 并使用直接 TLS；不允许用户指定主机、端口、代理或证书策略。
- 应用密码使用独立 `YANDEX_MAIL_CREDENTIALS_KEY` 通过 AES-GCM 加密，密文上下文绑定用户、
  账号和字段；API、日志和审计不返回敏感凭据或服务器原始响应。
- 首版不提供 SMTP、删除、移动、归档、星标或文件夹管理；唯一远端写入是精确 `\Seen` 更新。

### 升级说明

- 部署会应用 `0034_yandex_mail_imap.sql`；历史 `0032` 仍为永久保留编号，不得复用。
- 如需启用 Yandex Mail，创建至少 32 字节的 `YANDEX_MAIL_CREDENTIALS_KEY` Secret。
- 完成真实账号验证后设置 `YANDEX_MAIL_IMAP_ENABLED=true`，再由管理员在系统设置中开启入口。
- 未配置或未开启时不会展示入口、连接账号或调度 Yandex 同步，也不会影响其他邮箱 Provider。
