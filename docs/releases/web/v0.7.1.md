### 更新摘要

- QQ 邮箱账号现在可以管理多个已验证发信身份，包括 `@qq.com` 英文地址、Foxmail 和 QQ VIP
  地址，同时继续共用一个收件箱。
- 新建和回复邮件可选择发件身份；回复会优先匹配原邮件的收件地址。
- QQ 账号设置改为稳定高度的分层选项窗口，切换更紧凑、清晰且不会跳动。

### 新增

- 新增 QQ 邮箱身份管理，可手动添加 `@qq.com`、`@foxmail.com` 和 `@vip.qq.com` 地址，并在
  写信时选择已验证身份。
- 新增发信身份创建、删除 API 和审计记录；API Catalog 与生成式文档同步扩展为 13 个
  QQ 邮箱接口。
- 新增 D1 迁移 `0031_qq_mail_identities.sql`，为现有 QQ 账号自动建立主身份。

### 改进

- 回复邮件时根据原邮件收件地址自动选择相符身份，找不到时安全回退到主身份。
- QQ 账号设置首页只显示备注名称、邮箱身份、连接验证、同步账号、更新授权码和断开账号等
  紧凑选项，具体表单在独立子页中打开。
- 账号设置流程保持稳定的响应式高度，较长内容只在内部滚动；前进和返回使用方向一致的轻滑
  淡入动画，并遵循 `prefers-reduced-motion`。
- 子页切换后将焦点移至新标题，保持键盘焦点和读屏上下文连续。

### 修复

- 修复 QQ 账号设置页面因子页内容长度不同而反复改变外框高度的问题。
- 修复设置子页瞬间替换、缺少层级方向感的问题。
- 移除 QQ 邮件空阅读区中不必要的已读同步说明。

### 安全

- 附加身份必须先使用当前授权码通过 QQ SMTP 验证，验证成功后才保存；验证不会发送测试邮件。
- 发信接口只接受当前账号下已验证且启用的身份，未知发件地址会被拒绝；主身份不可删除。
- 授权码继续使用 `QQ_MAIL_CREDENTIALS_KEY` 加密，身份管理接口、日志和审计均不返回授权码。

### 升级说明

- 部署会自动应用 `0031_qq_mail_identities.sql`；现有 QQ 账号会自动回填主身份，无需重新连接。
- 无需新增 Worker 变量或 Secret。
- 英文 QQ、Foxmail 和 VIP 地址需由用户在 QQ 账号管理的“邮箱身份”中手动添加并完成验证。

### 测试

- 527 项 Web/Node 单元与组件测试、10 项 Worker 测试和 74 项 Playwright E2E 全部通过。
- 覆盖身份域名校验、SMTP 验证、身份创建与删除、主身份保护、未知发件人拒绝、写信和回复的
  身份选择，以及设置子页的固定高度、动画方向、返回和焦点行为。
- TypeScript、Oxlint、生产构建、发布元数据检查、D1 迁移幂等执行和 Wrangler dry-run 通过。
