### 更新摘要

- 新增完整的 QQ 邮箱工作区，可通过授权码聚合多个个人 `@qq.com` 账号的 INBOX。
- 支持受控 IMAP 同步、搜索、正文、附件、已读写入，以及通过 QQ 官方 SMTP 新建和回复邮件。
- QQ 邮箱接入既有的加密、Queue、幂等、限速、审计与响应式邮件阅读体验。

### 新增

- 支持连接、重命名、验证、更新授权码和断开多个个人 QQ 邮箱账号，并在全部账号与单账号
  范围之间切换。
- 首次索引最近 100 封 INBOX 元数据，每账号最多保留最近 500 封；支持本地元数据搜索、
  稳定游标分页和手动同步。
- 支持按需读取纯文本、HTML、CID 图片和最大 5 MiB 附件；打开未读邮件后精确同步 `\Seen`。
- 支持从当前 QQ 账号向单个收件人新建或回复邮件，发件人固定为当前账号地址。
- 管理员可在系统设置中独立隐藏 QQ 邮箱入口；API Catalog 和生成式 API 文档新增 11 个
  QQ 邮箱接口。

### 改进

- 抽取共享 IMAP 阅读器、范围切换器、搜索框和 SMTP 写信弹窗，供 Gmail 与 QQ 邮箱复用。
- QQ 邮件的回复按钮移至正文和附件之后，阅读标题栏只保留导航、标题与来源状态。
- 侧边栏品牌区增加 GitHub 仓库与 OmniMail 官网图标入口，提供 Tooltip、中英文可访问名称
  和安全的新窗口外链；窄侧栏与移动底栏保持原有布局。
- API 指南 E2E 使用实际 Catalog 数量验证全部端点，避免新增接口后重复计数失配。

### 修复

- 修复 QQ 邮件回复按钮曾出现在阅读标题栏、与邮件正文操作顺序不一致的问题。
- 修复 QQ 邮箱设置指南仍引用旧版顶部回复入口的问题。

### 安全

- 授权码由独立 `QQ_MAIL_CREDENTIALS_KEY` 使用 AES-GCM 加密，密文绑定用户、账号和凭据用途；
  API 只返回是否已配置，日志与审计不会记录授权码。
- IMAP 固定连接 `imap.qq.com:993` TLS，SMTP 固定连接 `smtp.qq.com:465` 直接 TLS；不接受
  QQ 登录密码、自定义主机、代理、TLS 降级或原始协议命令。
- 同步使用账号级租约，单账号故障不会阻断其他账号；正文和附件只按需读取且不持久化。
- SMTP 发送复用用户级速率限制与幂等键，并额外限制每个用户每天 50 封；`DATA` 后连接断开
  会标记为投递结果不确定且不自动重发，避免重复邮件。

### 升级说明

- 部署会按顺序应用 `0029_qq_mail_imap.sql` 与 `0030_qq_mail_smtp.sql` 两个 D1 迁移。
- 启用 QQ 邮箱前，在 Worker **Variables & Secrets** 中配置至少 32 字节且独立保存的
  `QQ_MAIL_CREDENTIALS_KEY`，然后重新部署。
- 用户需要在 QQ 邮箱设置中开启 IMAP/SMTP 服务并生成授权码；首版仅支持个人 `@qq.com`，
  不支持 Foxmail、VIP 或腾讯企业邮箱。
- 可设置 `QQ_MAIL_IMAP_ENABLED=false` 紧急隐藏入口并停止新的定时同步。不使用 QQ 邮箱的
  部署无需配置 Secret 或连接账号，其他邮箱功能不受影响。
