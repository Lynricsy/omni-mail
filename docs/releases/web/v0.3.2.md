### 更新摘要

- 修复完整 API 页面可带动根文档滚动、滚到底后出现大面积空白的问题。
- 完善 iCloud 隐藏邮箱用途标签和删除账号操作，降低重复输入与误操作风险。

### 改进

- iCloud 隐藏邮箱用途标签不再必填：留空时由系统使用 `OmniMail + 创建时间` 自动生成。
- 提供购物、社交、订阅、工作和临时使用快捷标签；选择后仍可在输入框中继续修改。
- “删除这个 iCloud 账号”使用明确的危险操作样式，补齐亮色、暗色、悬停、禁用和
  键盘焦点状态。

### 修复

- 登录后的工作区现在锁定根页面滚动，只允许邮箱、管理员和 API 内容区域内部滚动。
  修复完整 API 目录滚到底后侧边栏被卷走、页面下方出现大面积空白的问题。
- 保持移动端账号设置与 iCloud 导航原有定位行为，不再通过固定整个工作区规避滚动。

### 升级说明

- 无需新增 D1 迁移、Worker 变量或 Secret，正常重新部署即可。

### 测试

- 新增 API 页面根滚动回归测试，验证 102 个端点可以滚到末尾且 `window.scrollY` 保持 0。
- 覆盖 iCloud 自动生成、快捷选择、自定义用途标签和删除账号危险按钮。
- 完成 Web 单元测试、生产构建、53 项 Playwright E2E 和 Cloudflare Workers Build。
