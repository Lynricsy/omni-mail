### 更新摘要

- iCloud 邮箱新增 Apple IMAP 邮件搜索，并通过浏览器会话缓存减少重复等待。
- 优化邮件元信息、加载文案和查看范围弹窗，账号与收件地址切换过程更加稳定。
- 兼容旧版带连字符的备份身份 UUID，旧数据库无需手工改值即可继续备份。

### 新增

- iCloud 邮箱标题下方新增邮件搜索框，支持 300ms 防抖、取消失效请求、清空关键词和
  无结果状态。
- IMAP 模式使用 Apple 服务器执行邮件内容搜索并支持非 ASCII 关键词；Web 摘要模式可
  筛选当前已加载的邮件，并明确提示降级范围。

### 改进

- iCloud 邮件列表在浏览器会话内缓存约 60 秒，完整正文缓存约 10 分钟；缓存过期时先
  显示现有内容，再在后台获取最新结果。
- 手动同步会绕过新鲜缓存并请求 Apple；服务器确认 `\Seen` 后，相关列表缓存同步更新
  已读状态。
- 缓存按用户、iCloud 账号、收件地址和搜索词隔离，修改或删除账号时清理相关数据；刷新
  页面即清空，不写入 `localStorage`、IndexedDB 或公共缓存。
- 放大邮件阅读页的发件人、转发地址、收件地址和时间信息，改善间距与可读性；完整正文
  加载文案改为“正在从APPLE服务器获取邮件信息...”。
- iCloud 查看范围弹窗使用稳定的响应式高度和滚动槽位，异步加载邮箱时不再伸缩跳动；
  滚动条默认隐藏，在鼠标悬停或键盘焦点进入时显示。
- 查看范围弹窗关闭时增加短促的淡出、上移和缩小动画；账号与收件地址在退场完成后切换，
  并尊重系统“减少动态效果”设置。

### 修复

- 备份身份校验同时接受旧版标准 UUID 和新版 32 位十六进制格式，并统一大小写处理，修复
  部分旧数据库提示“服务器暂时无法处理这个请求”而无法创建备份的问题。
- iCloud 邮件列表和正文接口明确返回私有、禁止存储的缓存策略，避免 Cloudflare 或共享
  代理保存用户邮件内容。

### 安全

- iCloud 缓存仅存在当前页面会话内存中，不进行跨浏览器会话持久化。
- 缓存键包含用户和账号边界，账号凭据变更或删除时会清除关联邮件数据。

### 升级说明

- 从 `v0.3.6` 升级无需新增 D1 迁移、Worker 变量、Secret 或资源绑定。
- 旧版带连字符的备份身份 UUID 无需手工修改；升级后会被自动识别。
- OmniMail Float 与 Android 继续使用各自独立版本号，本次不随 Web 版本升级。
