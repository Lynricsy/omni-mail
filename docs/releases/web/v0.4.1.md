### 更新摘要

- 邮件阅读页新增滚动标题与双入口回顶，在浏览长邮件时持续显示当前邮件上下文。
- 优化邮件列表、顶部工具栏、管理员邮件抽屉和 iCloud 加载体验。
- 修复管理员邮件远程图片与跨工作区标题栏样式问题。

### 新增

- 邮件主标题完全滚出阅读区后，顶部“邮件详情”会替换为当前邮件标题。
- 点击顶部邮件标题或右下角回顶按钮，可以返回邮件顶部。

### 改进

- 标题切换使用“擦除后输入”的双向打字机动画；快速反向滚动会取消旧动画并直接转向
  新状态，长标题安全省略，系统启用“减少动态效果”时直接切换。
- 邮件列表改为 6px 短距离淡入和最多 110ms 的有限错峰，已有邮件在自动刷新时不会
  重复播放入场动画。
- 邮箱工具栏重新分组：文件夹标题保持左对齐，主要操作保持右对齐；刷新按钮回到主要
  操作区，桌面通知入口移到主题与语言控制区，移动端继续保留顶部通知入口。
- iCloud 首次按需加载使用工作区自身的轻量状态，不再复用管理统计页的悬浮卡片样式。

### 修复

- 主管理员邮件详情不再强制关闭远程图片；启用系统安全外部内容后，图片继续通过
  OmniMail 同源代理加载，不会让浏览器直接联系发件方。
- 主管理员邮件详情抽屉现在会先完成滑出与遮罩淡出再卸载，并统一处理关闭按钮、遮罩、
  Escape、焦点恢复和减少动态效果。
- 主邮箱两排标题栏样式限定到主邮箱工作区，iCloud 与 Linux DO Mail 恢复独立的单排
  标题和操作布局。
- 修复窄栏下长文件夹标题挤压操作按钮的问题，标题与操作组保持左右对齐且不产生横向
  溢出。

### 升级说明

- 无需新增 D1 迁移、Worker 变量、Secret 或 Cloudflare 资源绑定，正常重新构建并部署
  即可。
- 本次仅调整 Web 前端交互与布局，不改变邮件数据、凭据或现有 API 兼容性。

### 测试

- 通过 97 个测试文件、436 项单元测试，以及 3 个 Worker 集成文件、10 项绑定测试。
- 通过 65 项 Playwright 浏览器回归，新增覆盖滚动标题、双向打字机动画、回顶入口、
  列表入场、管理员图片代理与抽屉退场、窄栏工具布局及 iCloud 加载状态。
- 通过 TypeScript、文件行数限制、Web 生产构建、发布元数据检查和 Wrangler dry-run。
