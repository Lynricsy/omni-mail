### 更新摘要

- 新建邮件支持一次添加多个收件人，并以可删除标签清晰展示。
- 增加应用级崩溃恢复页，前端异常不再直接留下白屏。
- 接通 Cloudflare Workers Logs，为 QQ 同步和客户端崩溃提供可检索的结构化诊断信息。

### 新增

- 收件人输入支持回车、逗号、分号和批量粘贴，自动规范化与去重，单封最多 50 个地址。
- Resend 使用多地址投递；SendFlare 自动切换官方 `batchSend` 批量接口。
- 新增已认证的客户端异常上报接口；恢复页显示诊断编号，可在 Workers Logs 中按
  `crash_id` 定位。
- 新增 QQ 同步阶段日志，覆盖 `connect`、`examine`、`search`、`fetch_metadata`、
  `prepare` 和 `persist` 等阶段。
- 新增可观测性使用说明，记录日志入口、事件名称、关键字段和隐私边界。

### 改进

- 草稿继续沿用现有文本字段保存多个收件人，无需数据库迁移；旧单收件人草稿保持兼容。
- QQ 同步日志增加错误码、任务来源、重试次数、同步数量和耗时；首次或手动同步成功也会记录
  拉取数量，便于区分登录验证成功与后续同步失败。
- Workers Logs 显式使用 100% 采样；未处理 API 异常改为包含请求方法、路径和 Cloudflare Ray ID
  的结构化事件。
- API Catalog 增加客户端错误上报接口，当前共记录 168 个 Worker HTTP 端点。

### 修复

- 前端组件或懒加载模块发生未捕获渲染异常时，改为显示带明确恢复操作的错误页；重新加载后可
  继续使用，已提交到服务器的操作不会被撤销。
- 增加同一页面连续发送两封邮件的回归测试，防止第二次发送后邮箱根节点丢失或变成白屏。
- QQ 同步未知异常不再只留下笼统错误码；日志会指出失败阶段和安全化后的异常类型与信息。

### 安全

- 结构化日志在写入前移除控制字符、完整邮箱地址、URL 以及常见的授权码、密码、Token 和
  Secret 形态。
- 日志不记录邮件主题、正文、附件名、服务器响应原文或任何明文凭据。
- 客户端异常上报要求有效登录会话，限制字段长度，只提交页面路径而不提交查询参数。

### 升级说明

- 本版本不包含新的 D1 数据库迁移。
- 本版本不需要新增或修改 Cloudflare Variables、Secrets 或资源绑定。
- 已部署 `0.9.0` 的实例可以直接升级；Cloudflare Dashboard 中已启用的 Workers Logs 会自动
  接收新的结构化事件。

### 测试

- 585 项 Web/Node 单元与组件测试、10 项 Worker 集成测试全部通过。
- Playwright E2E 覆盖多收件人、连续两次发送、草稿恢复与移动端布局。
- TypeScript、Oxlint、API Catalog 生成、生产构建和 Wrangler dry-run 通过。
