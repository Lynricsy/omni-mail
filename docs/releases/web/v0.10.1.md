### 更新摘要

- Web/API 为 OmniMail Float 增加 Microsoft、NAVER 与 Yandex 最小只读授权，并统一
  展示已连接第三方邮箱的数据访问范围。
- 已有 `0.4.0` 令牌在用户确认升级前继续保留 Gmail/QQ 读取，不会静默获得新来源。

### 新增

- Float 设备 Scope 新增 Microsoft、NAVER、Yandex 的账号公开元数据、邮件列表和正文
  读取。
- Scope 中间件只接受三个来源的账号列表、邮件列表和单封正文 GET 路径。
- 扩展授权页及英文翻译更新为五类已连接第三方邮箱。

### 安全

- Microsoft 文件夹、三个来源的账号连接/修改、主动同步、附件和其他写接口继续返回
  `403`。
- Refresh Token 轮换保持原 Scope；重新完成 Chrome Identity、PKCE 和网站确认后才会
  签发包含新来源的会话。
- Float 仍不能读取 Microsoft OAuth Token、组合密码、NAVER/Yandex 应用密码或网页
  登录 Cookie。

### 升级说明

- 无需 D1 迁移、新增变量、Secret 或资源绑定。
- 未使用 Float 或暂不升级 Float `0.4.1` 的部署不受影响。

### 测试

- 通过 TypeScript、Oxlint、设备 Scope/适配器单元测试和扩展授权 Playwright E2E。
- 覆盖新来源允许的 GET 路径、写操作拒绝，以及部分旧 Scope 保留 Gmail/QQ 的兼容行为。

### 发布

- Web 版本为 `0.10.1`；通过 GitHub Tag `v0.10.1` 发布，无额外 Web 下载文件。
- OmniMail Float 使用独立 Tag `float-v0.4.1` 和 ZIP，不上传 Chrome Web Store。
