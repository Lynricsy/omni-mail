### 更新摘要

- iCloud 邮件新增真实 IMAP 已读状态同步、隐藏邮箱排序和更清晰的审计日志。
- 强化发信幂等、R2 删除、存储配额、备份隔离和密码变更后的会话安全。
- 减少 Worker 启动与重复部署中的 D1 冷路径和无效迁移工作。

### 新增

- iCloud 收件地址支持按名称、最新创建时间或邮箱地址排序；名称使用自然数字顺序，
  “全部邮件”固定在顶部，停用地址保持靠后。
- iCloud IMAP 列表读取服务器 `FLAGS` / `\Seen` 状态；未读邮件显示状态点、字体强调和
  屏幕阅读器说明，打开后使用 `UID STORE +FLAGS.SILENT (\Seen)` 同步回 iCloud。
- 操作日志增加独立的 iCloud 分类、可读动作名称、账号名称、隐藏邮箱地址和用途标签；
  搜索同时覆盖 iCloud 账号和结构化详情。
- 新增 D1 迁移 `0022_consistency_guards.sql`，用于暂存待删除 R2 对象、约束每个用户只能
  有一个主邮箱，并让草稿变更推进邮件状态版本。

### 改进

- iCloud 排序入口改为紧凑的自定义菜单，保留 44px 点击范围、键盘焦点、Escape 和
  点击外部关闭，并优化小屏文字层级。
- 发信幂等键按用户隔离；SendFlare 与 Resend 的投递结果、失败状态和重试边界更加明确。
- 邮件永久删除先在 D1 登记待删除对象，再清理 R2；对象删除失败时可由后续清理任务恢复。
- 备份对象按实例身份隔离，备份浏览与恢复仅访问当前实例范围。
- Web、管理页和 OmniMail Float 的异步列表与正文请求增加取消和请求序号保护，避免快速
  切换后旧响应覆盖当前状态。
- Worker Schema 检查以最新迁移为正常快速路径；健康检查不再访问 D1，跨区域冷启动请求
  获得更合理的等待时间。
- 远程部署只对新数据库或旧结构执行 Legacy Bootstrap，已更新数据库直接检查并应用待办
  迁移，减少重复部署的可用性窗口。

### 修复

- 阻止 SendFlare 在网络结果不确定或服务商已接收但本地落库失败时自动重复投递。
- 修复并发永久删除可能重复释放配额、重复清理对象或错误统计删除数量的问题。
- 修复草稿创建、更新和删除后的状态版本不同步，以及并发创建主邮箱可能产生多个主地址的
  一致性问题。
- 修改密码时撤销其他浏览器与设备会话，并为当前浏览器安全轮换会话。
- iCloud Web 摘要不再显示或伪造 IMAP 已读状态；只有服务器确认 Seen 后才更新界面。

### 安全

- iCloud 审计详情不会记录 Cookie、应用专用密码或其他凭据。
- 用户级发信幂等、实例级备份命名空间和所有权约束降低跨账号、跨实例数据混淆风险。
- 邮件和附件删除在确认所有权与数据库删除成功后才释放配额并清理对象。

### 升级说明

- 从 `v0.3.5` 升级时会自动应用 D1 迁移 `0022_consistency_guards.sql`。
- 无需新增 Worker 变量、Secret 或资源绑定，使用现有部署流程即可。
- OmniMail Float 与 Android 继续使用各自独立版本号，本次不随 Web 版本升级。
