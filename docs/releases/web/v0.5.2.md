### 更新摘要

- 修复 Gmail 查看范围弹层在独立工作区中丢失样式的问题，恢复与 iCloud 范围选择器一致
  的布局、层级和响应式体验。
- 收件趋势图改用 OmniMail 统一悬浮提示，替代与网站风格不一致的浏览器原生提示。

### 修复

- Gmail 查看范围组件现在自行加载所依赖的共享样式，直接访问 `/gmail` 时不再出现原生
  按钮、错误堆叠或弹层占据页面文档流的情况。
- 增加弹层计算样式与视口边界回归检查，确保弹层使用浮层定位且不会超出当前窗口。

### 改进

- 趋势图数据点悬浮时沿用站内统一的黑白半透明提示样式，显示精确日期和收件数量。
- 数据点支持键盘聚焦与读屏标签，聚焦态与鼠标悬浮态保持一致；提示动效继续遵循系统
  “减少动态效果”设置。

### 升级说明

- 无需新增 D1 迁移、Worker 变量、Secret 或资源绑定，现有 `v0.5.1` 部署可直接升级。
- Gmail、iCloud 和 Linux DO 的现有账号、凭据及邮件索引无需重新配置。

### 测试

- 自动化测试覆盖 Gmail 查看范围弹层的定位与视口边界，以及趋势图数据点的键盘入口和
  统一悬浮提示。
- 发布候选通过 Web、Worker、Playwright、浏览器扩展、TypeScript、React Hooks lint、
  文件行数限制、生产构建、发布元数据检查和 Wrangler dry-run。

### 发布

- Web 版本为 `0.5.2`；通过 GitHub Tag `v0.5.2` 发布，无额外 Web 下载文件。
- 本次 Web Release 不包含 OmniMail Float 扩展包或 Android 安装包。
