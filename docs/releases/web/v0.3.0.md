### 更新摘要

- 新增独立的 iCloud+ Hide My Email 工作区，可在 OmniMail 中管理隐藏邮箱地址并按需读取最近来信。
- iCloud 凭据加密保存，账号、地址和邮件数据按当前 OmniMail 用户严格隔离。

### 新增

- 支持连接 `icloud.com` 与 `icloud.com.cn` 账号，同步、创建、停用、恢复和删除隐藏邮箱地址。
- 支持使用应用专用密码通过 iCloud IMAP 筛选最近来信并读取完整正文。
- IMAP 不可用时，全部邮件视图可以回退到 iCloud Web 摘要。
- 新增独立 `/icloud` 工作区，并复用现有登录、权限、主题、语言和响应式导航。

### 改进

- iCloud HTTP 与 IMAP 请求增加超时、安全重试和请求取消边界。
- 别名写操作不再自动重放不确定的网络失败，地址统计以 Apple 返回列表为准。
- 弹窗支持进退场过渡、Escape、焦点循环与焦点恢复，复制地址会显示明确结果。
- 将 iCloud 重构为与 OmniMail 收件箱一致的邮件列表与常驻阅读区，并明确标识
  Cookie Web 摘要和 IMAP 完整邮件两种模式。
- IMAP 完整邮件保留 HTML 正文并通过沙箱与 CSP 安全渲染，纯文本链接继续使用
  OmniMail 外链确认。
- 远程图片遵循系统设置并通过同源代理加载，列表栏图标操作补齐悬浮说明。

### 安全

- 新增 `ICLOUD_CREDENTIALS_KEY`，使用绑定用户、账号与字段上下文的 AES-GCM 加密
  iCloud Cookie 和应用专用密码；API 永不回传凭据。
- 限制 Cookie 数量、单值大小、总大小和非法请求头字符。
- OmniMail Float 的受限设备令牌不能访问 iCloud 凭据与接口。

### 升级说明

- 部署会应用 D1 迁移 `0021_icloud_accounts.sql`。
- 使用 iCloud 功能前必须配置至少 32 字节的 `ICLOUD_CREDENTIALS_KEY` Worker Secret。
- iCloud 邮件按需从 Apple 读取，不会复制到 OmniMail 的 D1、R2 或现有收件箱。

### 测试

- 覆盖凭据加密、Apple 响应解析、IMAP、用户隔离、设备 Scope 和 D1 迁移恢复。
- 覆盖桌面与移动端 iCloud 工作区端到端流程。

### 发布

- Web 版本为 `0.3.0`。
- OmniMail Float 保持独立版本，本次 Web 发布不包含扩展包。
