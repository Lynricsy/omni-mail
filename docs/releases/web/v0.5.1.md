### 更新摘要

- iCloud、Linux DO 与 Gmail 邮件详情补齐与域名邮箱一致的顶部标题和快速回顶体验。
- 所有邮件列表均可点击页面标题返回顶部，长列表浏览后无需手动拖动滚动条。
- 优化首屏资源加载、邮件正文渲染和新邮件通知请求，降低等待时间与内存开销。

### 新增

- iCloud、Linux DO 与 Gmail 邮件主标题滚出阅读区后，顶部工具栏会动画显示当前邮件
  标题；点击标题或右下角悬浮按钮均可返回详情顶部。
- 域名邮箱的收件箱、星标邮件、草稿箱、已发送和垃圾箱，以及 iCloud、Linux DO、Gmail
  邮件列表支持点击页面大标题返回列表顶部。
- 列表标题提供完整键盘焦点状态和足够的点击区域，平滑滚动同时兼容“减少动态效果”。

### 改进

- Gmail 功能未配置时继续保留邮件双栏结构，并使用与 iCloud、Linux DO 一致的空状态，
  避免提示孤立在整页空白区域。
- 英文完整翻译目录改为按需加载，中文首屏只保留必要核心翻译；管理页面、外部邮箱和其他
  独立工作区的样式也随对应模块加载。
- HTML 邮件内嵌图片改用 Blob URL，避免转换为较大的 Base64 字符串，并在切换邮件后
  主动释放；正文宽度已经适配阅读区时跳过逐元素布局扫描。
- 新邮件通知记录全局收件箱版本，在浏览其他文件夹时仅于版本变化后重新读取收件箱。
- 邮件请求状态、API 客户端、邮件安全文档构建、管理后台、认证页面、邀请管理及浏览器
  扩展面板拆分为更小模块，降低维护复杂度。
- 新增 React Hooks lint，并将前端实现文件的行数限制收紧为 500 行。

### 修复

- 修复 Linux DO 工作区独立加载时未显式包含共享详情样式，导致移动端邮件详情可能保持
  隐藏的问题。
- 修复英文模式首次加载完整翻译目录前可能短暂显示中文功能文案的问题。

### 升级说明

- 无需新增 D1 迁移、Worker 变量、Secret 或资源绑定，现有 `v0.5.0` 部署可直接升级。
- Gmail、iCloud 和 Linux DO 的现有账号、凭据及邮件索引无需重新配置。

### 测试

- 自动化测试覆盖域名邮箱及 iCloud、Linux DO、Gmail 的列表回顶、详情标题动画、标题
  回顶、悬浮按钮和响应式布局。
- 覆盖英文目录按需加载、邮件内嵌图片安全策略、正文尺寸快速路径、新邮件通知版本复用、
  Gmail 未配置状态及 Linux DO 移动端详情。
- 发布候选通过 106 个文件共 465 项 Web 测试、3 个文件共 10 项 Worker 测试、69 项
  Playwright，以及浏览器扩展检查。
- 通过 TypeScript、React Hooks lint、文件行数限制、生产构建、发布元数据检查和
  Wrangler dry-run。
