### 更新摘要

- 新增完整的 Microsoft 邮箱工作区，通过 OAuth2 + IMAP XOAUTH2 聚合多个 Outlook.com、
  Hotmail、Live 和允许 IMAP 的 Microsoft 365 委托式账号。
- 支持安全批量导入、账号批量管理、全部账号同步、文件夹浏览、搜索、正文、附件和精确已读同步。
- Microsoft 弹窗、滚动区域和逐项导入动画完成稳定性与移动端优化。

### 新增

- 提供分字段录入与两步批量导入，支持以下两类 OAuth2 凭据：

  ```text
  email----password----refresh_token----client_id
  email----password----client_id----refresh_token
  email--------refresh_token----client_id
  ```

- 完整组合中的 password 只有在用户明确确认后才会独立加密留存，永不参与认证或认证回退。
- 工作区支持全部账号 INBOX 聚合、单账号文件夹、25/50/100/200 条分页、本地元数据搜索、
  Queue 同步与当前文件夹远程刷新。
- 支持按需读取纯文本、HTML、CID 图片和最大 5 MiB 附件；打开未读邮件后精确同步 `\Seen`。
- 账号管理支持备注、重新验证、替换 OAuth2 凭据、单个断开和批量断开。
- 顶部复制按钮在全部范围默认复制第一个账号邮箱，范围面板可直接复制任意账号邮箱。

### 改进

- Microsoft 连接、批量导入和账号管理弹窗统一响应式高度，标题与操作区保持稳定，超出内容只
  在内部滚动。
- 批量导入增加输入与安全确认步进页面；逐项验证时显示转圈，成功后显示对勾并平滑移出。
- 滚动条默认隐藏，仅在悬停、聚焦或滚动时渐显；动画尊重 `prefers-reduced-motion`。
- 完善键盘焦点、可访问名称、错误提示、危险操作二次确认和导入进度反馈。

### 安全

- Microsoft 认证只允许 OAuth2 + IMAP XOAUTH2；仅邮箱密码、IMAP LOGIN、ROPC 和 OAuth2
  失败后的密码回退均未开放。
- OAuth endpoint、authority 形式、IMAP 主机和端口由服务端固定，不接受任意 URL、代理、
  TLS 策略或原始 IMAP 命令。
- refresh token、短期 access token 和可选组合 password 使用独立 Secret 与 AES-GCM 加密，
  密文绑定用户、账号和凭据类型。
- 唯一开放的远端写入是对已验证 folder、UIDVALIDITY 与 UID 添加 `\Seen`；正文和附件不持久化。

### 升级说明

- 新增 D1 迁移 `0027_microsoft_imap.sql` 与
  `0028_microsoft_oauth_combination_password.sql`，部署脚本会按顺序自动应用。
- 启用 Microsoft 邮箱前，必须配置至少 32 字节的 Secret `MICROSOFT_CREDENTIALS_KEY`。
- 可选设置 `MICROSOFT_MAIL_ENABLED=false` 隐藏入口并停止定时同步入队；不配置 Secret 时功能
  保持关闭，其他邮箱功能不受影响。
- 部署者需自行准备 refresh token、Client ID 与 authority，并确保令牌拥有
  `https://outlook.office.com/IMAP.AccessAsUser.All` 和 `offline_access`。
