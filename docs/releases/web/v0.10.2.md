### 更新摘要

- Web/API 为 OmniMail Float 增加 Linux DO Mail 最小只读授权，完成八类 Web 邮箱来源的
  Float 读取基线。
- 旧 Float `0.4.1` 令牌不会静默获得 Linux DO 权限，用户需明确确认一次升级授权。

### 新增

- Float 设备 Scope 新增 Linux DO 脱敏账号、INBOX/已发送列表和正文读取。
- Scope 中间件只接受 Linux DO 账号、收件箱、已发送和单封正文 GET 路径。
- 授权页与隐私说明更新为八类邮箱来源。

### 安全

- Linux DO 连接、凭据、验证、发信以及其他写操作继续返回 `403`。
- Refresh Token 轮换保持原 Scope；重新完成 Chrome Identity、PKCE 和网站确认后才会
  签发包含 Linux DO 的会话。
- Float 仍不能读取 Linux DO 密码或认证令牌，也不直连远端 IMAP/SMTP。

### 升级说明

- 无需 D1 迁移、新增变量、Secret 或资源绑定。
- 未使用 Float 或暂不升级 Float `0.4.2` 的部署不受影响。

### 测试

- 通过 TypeScript、Oxlint、设备 Scope/适配器单元测试、扩展授权 Playwright E2E、
  七来源 Chromium smoke 和 Wrangler dry-run。
- 覆盖旧 Scope 保留既有来源、升级后 Linux DO 发现、收件箱/已发送切换及正文读取。

### 发布

- Web 版本为 `0.10.2`；通过 GitHub Tag `v0.10.2` 发布，无额外 Web 下载文件。
- OmniMail Float 使用独立 Tag `float-v0.4.2` 和 ZIP，不上传 Chrome Web Store。
