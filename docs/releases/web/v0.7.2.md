### 更新摘要

- QQ 和 Gmail 邮箱同步改为小批次增量处理，降低大邮箱同步超时和长期停留在“正在同步”的风险。
- QQ/Gmail 手动同步支持选择本次最多同步 10、20 或 50 封邮件。
- Gmail 账号设置改为与 QQ 一致的二级设置窗口，QQ SMTP 发件身份下拉菜单也统一为可访问的自定义菜单。

### 新增

- 新增统一的手动同步数量选择器，默认使用 20 封安全批次。
- 新增 Gmail 同步的分段 UID 搜索，避免对超大 INBOX 使用无界 `UID SEARCH ALL`。

### 改进

- QQ/Gmail 后台同步每轮只刷新最近 20 封状态，并按请求数量处理新增邮件；本地索引仍最多保留 500 封。
- 自动恢复租约已过期的同步任务，并记录脱敏同步错误码。
- Gmail 账号设置采用 QQ 同款的账号摘要、二级目录、返回导航和危险操作确认流程。
- QQ SMTP 发件人候选项改为显示身份名称、邮箱地址和选中状态，支持键盘导航与 Escape 关闭。

### 修复

- 修复 QQ/Gmail Worker 被中途终止后账号永久停留在 `syncing` 的问题。
- 修复大邮箱每轮重复读取最多 500 封元数据导致同步任务超时的问题。
- 修复 Gmail 设置窗口内容过长、操作层级与 QQ 不一致的问题。
- 修复主管理员的“所有邮箱”收件箱未显示无人收件邮件的问题。

### 安全

- 手动同步数量只接受 10、20、50 三个受控值；后台任务未携带数量时使用默认值 20。
- 同步错误日志只记录账号内部标识和脱敏错误码，不记录邮件内容或凭据。

### 升级说明

- 本版本不新增 D1 迁移，也不要求新增 Worker Secret 或变量。
- 已有 QQ/Gmail 账号和邮件索引无需重新连接；下一次定时任务会自动采用新的同步策略。

### 测试

- 538 项 Web/Node 单元与组件测试、10 项 Worker 测试全部通过。
- 覆盖 Gmail 分段 UID 搜索、QQ/Gmail 同步批次、过期租约恢复、同步数量校验和自定义选择器行为。
- TypeScript、Oxlint、生产构建、API 文档生成和 Cloudflare 健康检查通过。

### 发布

- Web 版本为 `0.7.2`；通过 GitHub Tag `v0.7.2` 发布，无额外 Web 下载文件。
- 本次 Web Release 不包含额外邮箱适配、OmniMail Float 扩展包或 Android 安装包。
