### 更新摘要

- 新增 NAVER Mail 只读 IMAP 工作区，可在 OmniMail 中集中管理多个个人 `@naver.com` 邮箱。
- 支持有限 INBOX 索引、搜索、按需正文与附件读取，并在打开邮件时精确同步远端已读状态。
- 功能默认关闭，必须配置独立加密密钥、生产环境开关并由管理员开启入口。

### 新增

- 新增 NAVER Mail 账号连接、重命名、连接验证、应用专用密码更新、手动同步和断开 API。
- 新增 NAVER 邮件聚合列表、稳定游标分页、账号筛选、搜索、按需正文及附件下载。
- 新增 NAVER 专用 API Catalog、设置指南、部署检查、管理员入口开关、审计事件和 E2E 覆盖。
- 新增 D1 迁移 `0033_naver_mail_imap.sql`，保存账号密文、有限邮件元数据和验证限速状态。

### 改进

- 首次同步最近 100 封邮件；后续单轮最多拉取 20 封新增邮件并刷新最近 20 封状态。
- 每个账号最多保留最近 500 封 INBOX 元数据，正文和附件只在用户打开时读取，不写入 D1 或 R2。
- 自动恢复过期的同步租约，并在 Queue 失败时只记录账号内部标识和脱敏错误码。
- 兼容 NAVER 实际返回的 `UIDVALIDITY 0`，同时保留 UIDVALIDITY 变化时重建本地索引的能力。

### 修复

- 修复 NAVER 大邮箱重复读取全部本地索引、容易导致后台同步长时间运行的问题。
- 修复 Worker 被中途终止后账号可能永久停留在 `syncing` 状态的问题。
- 修复 NAVER 返回零 UIDVALIDITY 时登录成功却被误报为连接失败的问题。

### 安全

- 仅接受个人 `@naver.com` 邮箱和 NAVER 应用专用密码；不接受账号主密码或企业域名。
- 固定连接 `imap.naver.com:993` 并使用直接 TLS；不允许用户指定主机或端口。
- 本版本不提供 NAVER SMTP、删除、移动、归档、星标或其他远端写操作；唯一允许的远端写入是
  打开邮件后的精确 `\\Seen` 更新。
- 应用专用密码使用独立的 `NAVER_MAIL_CREDENTIALS_KEY` 通过 AES-GCM 加密，API、日志和审计不返回
  密码、密文、长度或掩码片段。
- 凭据验证按用户和 IP 限速；功能关闭时停止新连接、手动同步、正文读取和后台调度。

### 升级说明

- 创建至少 32 字节的 `NAVER_MAIL_CREDENTIALS_KEY` Secret。
- 完成真实账号验证后，在生产环境设置 `NAVER_MAIL_IMAP_ENABLED=true`，并在系统设置中开启
  NAVER 邮箱入口。
- NAVER 账号需要先开启两步验证和 IMAP/SMTP，再为 OmniMail 创建独立应用专用密码。
- 部署会应用 `0033_naver_mail_imap.sql`；`0032` 为永久保留编号，不需要空迁移，后续迁移从
  `0034` 开始。
- 曾使用测试数据库迁移的安装会按完整迁移名称单独识别并应用 `0033`，不删除测试期遗留表。
