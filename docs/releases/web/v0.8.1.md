### 更新摘要

- 修复系统设置中“部署初始化向导”入口首次显示为浏览器原生按钮的问题。
- 入口样式现在随管理员页面加载，不再依赖尚未打开的部署向导弹窗资源。

### 改进

- 补充入口按钮的键盘焦点状态和窄屏布局，保持与系统设置卡片的视觉和交互一致。

### 修复

- 修复部署向导组件采用懒加载时，入口按钮对应 CSS 尚未加载而出现无样式闪烁的问题。

### 升级说明

- 本版本不包含新的 D1 数据库迁移。
- 本版本不需要新增或修改 Cloudflare Variables、Secrets 或其他绑定。
- 已部署 `0.8.0` 的实例可以直接升级。

- 556 项 Web/Node 单元与组件测试、10 项 Worker 测试全部通过。
- 部署设置相关 Playwright E2E 通过，覆盖入口样式与部署向导打开流程。
- TypeScript、Oxlint、API 文档生成和生产构建通过。
