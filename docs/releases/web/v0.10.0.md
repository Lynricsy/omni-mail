### 更新摘要

- Web/API 为 OmniMail Float 增加 Gmail 与 QQ 邮箱最小只读授权，并在授权页明确展示新增
  数据访问范围。
- 旧扩展令牌不会静默获得新权限，用户升级 Float 后需要在 OmniMail 网站重新确认一次。

### 新增

- Float 设备 Scope 新增 Gmail/QQ 账号公开元数据、邮件列表和正文读取。
- Scope 中间件只接受 Gmail/QQ 的账号列表、邮件列表和单封正文 GET 路径。
- 扩展授权页新增“已连接的 Gmail 与 QQ 邮箱”权限说明及英文翻译。

### 安全

- Gmail/QQ 账号连接、凭据更新、同步、附件、QQ 发件身份和发信接口继续返回 `403`。
- Refresh Token 轮换保持原 Scope；只有重新完成 Chrome Identity、PKCE 和网站确认流程
  才会签发包含新增只读 Scope 的会话。
- Float 仍不能读取 Gmail 应用密码、QQ 授权码、网页登录 Cookie 或其他第三方凭据。

### 升级说明

- 无需 D1 迁移、新增变量、Secret 或资源绑定。
- 未使用 Float，或暂不升级 Float `0.4.0` 的部署不受影响。

### 测试

- 通过 TypeScript、Oxlint、设备 Scope 单元测试和扩展授权 Playwright E2E。
- 覆盖允许的账号/邮件 GET 路径，以及连接、同步、附件、身份和发信拒绝路径。

### 发布

- Web 版本为 `0.10.0`；通过 GitHub Tag `v0.10.0` 发布，无额外 Web 下载文件。
- OmniMail Float 使用独立 Tag `float-v0.4.0` 和 ZIP，不上传 Chrome Web Store。
