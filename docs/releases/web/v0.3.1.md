### 更新摘要

- 在 Webmail 内提供完整、可搜索的 API 使用手册，覆盖当前 Worker 的全部 102 个
  HTTP API，并为每个接口提供可复制调用示例。
- 修复 iCloud 隐藏邮箱创建响应兼容问题，并完善创建后自动切换和快捷复制体验。

### 新增

- 新增 `/settings/api` 工作区，所有登录用户均可查看当前实例 API Base URL、Bearer
  Token 获取、刷新与撤销流程。
- 提供 cURL、JavaScript、Python、n8n 与 Postman 接入示例，说明 MFA、跨域、令牌
  保存和仅 Linux DO 账户的现有限制。
- 按系统、认证、邮箱、邮件、草稿、iCloud 和管理员能力分组记录全部 102 个 HTTP API。
  每个端点均包含认证权限、请求参数、成功响应、使用限制和动态生成的 cURL 示例。
- API 目录支持按路径、方法、用途或字段搜索；路由覆盖测试会直接扫描 Worker 主路由及
  子路由文件，防止后续新增接口时遗漏文档。

### 改进

- iCloud 隐藏邮箱范围选择器为每个地址增加独立复制按钮，点击不会切换邮箱或关闭弹层。
- 创建新隐藏邮箱后自动选中新地址、同步别名列表并加载该地址的收件箱。
- API 目录适配桌面、移动端、深色主题与中英文界面，并支持键盘展开和复制反馈。
- API 目录独立按需加载，不增加邮件管理、用户和系统设置页面的首次打开体积。

### 修复

- 兼容 Apple Hide My Email `generate` 接口当前返回的扁平 `result.hme` 字符串，同时
  继续兼容旧的嵌套对象，修复创建地址时误报“iCloud 响应中没有隐藏邮箱地址”。

### 升级说明

- 无需新增 D1 迁移、Worker 变量或 Secret，正常重新部署即可。
- 已启用 iCloud 的实例沿用现有 `ICLOUD_CREDENTIALS_KEY`，无需重新保存账户凭据。

- 覆盖 iCloud 当前与旧响应格式、创建后自动切换、快捷复制和收件地址请求。
