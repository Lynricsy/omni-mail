### 更新摘要

- 改善登录、邮件列表和邮件阅读体验，修复键盘遮挡输入区域与深色模式正文不协调的问题。
- 邮件列表新增星标、长按操作、一键已读和下拉刷新，常用管理操作不再需要进入详情页。
- 邮件详情将回复和转发固定在页面底部，便于单手操作。

### 新增

- 邮件列表每封邮件提供星标按钮。
- 长按邮件可标为已读或未读、添加或取消星标，以及移到回收站。
- 回收站长按邮件可恢复或永久删除；永久删除前会再次确认。
- 支持将当前已经加载的邮件一键全部标为已读。
- 支持在邮件列表顶部下拉刷新。
- 支持从邮件详情直接转发邮件。

### 改进

- 邮件正文会跟随应用深色模式，并兼容声明仅支持浅色显示的邮件内容。
- 回复和转发按钮固定显示在邮件详情底部。
- 调整登录页的系统安全区域与软键盘避让，输入时页面内容不再被异常挤压。

### 已知限制

- “当前列表全部已读”仅处理已经加载到列表中的邮件；尚未分页加载的邮件不会被修改。
- 当前版本支持纯文本写信、回复与转发，尚未支持附件上传和服务端草稿。
- 邮件附件可查看名称与大小，暂不支持下载。

### 安装与升级

- 需要 Android 8.0 或更高版本。
- 从正式版 `android-v0.1.0` 可直接覆盖升级，并保留登录状态和应用数据。
- debug APK 使用不同证书，安装本正式版前需要先卸载 debug 版本。

### 测试

- 通过 31 项 Android 单元测试、release Lint、release APK 构建和签名校验。
- 已在 Pixel 9 Pro 模拟器验证邮件星标、长按操作、一键已读、下拉刷新、深色正文、回复和转发布局。
