### 更新摘要

- 将 Web 端 iCloud+ Hide My Email 工作流带到原生 Android，并补齐账号、地址与最近来信管理。
- 完成服务端草稿、附件上传下载、离线缓存、后台同步、新邮件通知和邮件深链。
- Android 设备令牌改为最小权限，并自动向下收紧升级前创建的全权限会话。

### iCloud

- 新增独立 iCloud 页面，支持 `icloud.com` 与 `icloud.com.cn` 账号。
- 支持添加、重命名和删除账号，更新 Cookie、iCloud 邮箱及应用专用密码。
- 支持选择、复制、停用、恢复和永久删除隐藏邮箱地址。
- 创建前显示 Apple 候选地址并可更换；一次顺序创建 1–5 个，支持独立标签、进度和部分失败恢复。
- 支持全部邮件或按隐藏地址读取最近 7 天来信，区分 IMAP 完整邮件和 Web 摘要。
- 识别 Hide My Email 中继发件人；Apple 凭据或权限 `422` 错误不会退出 OmniMail 登录。

### 草稿与附件

- 新建和转发邮件会自动保存为服务端草稿，可从草稿列表继续编辑或永久丢弃。
- 支持最多 5 个附件、单个 5 MiB、总计 10 MiB，并显示上传与草稿保存状态。
- 新邮件和转发通过草稿幂等发送；回复支持 multipart 附件。
- 收件附件通过 Android 系统文件保存器下载，不申请广泛存储权限。

### 离线、同步与通知

- 使用 Room 缓存最近 200 封邮件及已打开正文；飞行模式可恢复账号并只读查看缓存。
- 使用 WorkManager 在联网条件下每 15 分钟同步，设置页可以关闭后台同步。
- Android 13 及以上按需申请通知权限；锁屏通知只显示发件人，不显示主题和正文。
- 通知通过 `omnimail://message/{id}` 深链直接打开对应邮件。
- 退出登录会清除当前账号的本地邮件与会话元数据；Refresh Token 仍仅保存在 Android Keystore。

### 安全

- 新登录和刷新登录均声明 Android 客户端类型；Worker 只授予账户资料、邮件、草稿、附件和 iCloud 所需权限。
- 旧 `*` Android 会话首次刷新时自动向下收紧，受限的 Float 会话不会被扩大权限。
- HTML 阅读器继续禁用 JavaScript、表单、文件访问和内容访问，外链仍由系统浏览器确认处理。

### 测试

- 新增 Android 令牌声明、Room 离线筛选、iCloud 中继发件人与日期显示单元测试。
- 新增 360dp 手机单栏、840dp 平板双栏和草稿列表 Compose 仪器测试。
- Android Release CI 编译全部仪器测试，并继续运行单元测试、Lint、构建和签名校验；4 项 Compose 测试已在 Pixel 9 Pro AVD 实际运行通过。

### 安装与升级

- 需要 Android 8.0 或更高版本。
- 可从 `android-v0.2.0` 直接覆盖升级；首次令牌刷新会自动应用新的权限范围。
- Room 数据库从本版本开始创建，不需要服务端新增 D1 迁移或 Worker 资源绑定。
