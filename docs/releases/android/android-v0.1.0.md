### 更新摘要

- OmniMail 首个 Android GitHub 发行版，可连接自行部署的 OmniMail 实例。
- 提供接近 Gmail 的邮件列表、阅读、搜索、写信和回复体验。
- 支持简体中文与 English，并适配浅色、深色和跟随系统主题。

### 新增

- 分步登录流程，支持实例地址、账号密码和按需二步验证码。
- 支持收件箱、已发送、星标和回收站，以及分页加载和多邮箱筛选。
- 支持选择不同发件邮箱写信，并从邮件详情直接回复。
- 邮件详情显示本地化收件时间及明确的 `GMT±HH:mm` 时区偏移。
- 提供远程图片保护、外部链接确认和应用内版本检查。

### 安全

- 正式 APK 使用固定发布证书签名，以支持后续原地更新。
- 刷新令牌通过 Android Keystore 与 AES-GCM 加密后保存在设备上。
- 正式版本仅允许 HTTPS 实例，邮件正文禁用 JavaScript、文件访问和混合内容。

### 已知限制

- 当前版本支持纯文本写信与回复，尚未支持附件上传和服务端草稿。
- 邮件附件可查看名称与大小，暂不支持下载。

### 安装与升级

- 需要 Android 8.0 或更高版本。
- 之前安装的 debug APK 使用不同证书，首次安装正式版前需要卸载一次。
- 从本版本开始，只要发布证书保持不变，后续 Android Release 可直接覆盖更新。

### 测试

- 通过 Android 单元测试、release Lint、release APK 构建和签名校验。
- 已在 Android 模拟器完成登录、邮箱切换、搜索、阅读、写信和回复流程验证。
