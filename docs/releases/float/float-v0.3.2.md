### 更新摘要

- 修复快速切换邮箱或返回列表时，较慢的旧请求可能覆盖当前邮件列表或详情的问题。
- OmniMail 登录失效后立即清除面板中的账户和邮件状态，已读写入失败也会显示真实错误。
- 补充授权前数据用途说明，并更新 Chrome Web Store 的 iCloud 功能截图与审核填写稿。

### 改进

- 扩展连接页在保存站点地址和打开授权页前，明确说明授权后会处理的数据及其用途。
- 商店说明补齐普通邮箱、iCloud 隐藏邮箱、双来源收件、权限理由、数据类型和无远程代码
  声明。

### 修复

- 普通邮箱和 iCloud 邮件详情会丢弃已过期的异步响应，切换筛选或返回列表后不会被旧
  请求覆盖。
- 扩展会响应登录存储变化；令牌失效或退出后不再保留旧账户、邮箱和邮件画面。
- 标记已读失败时不再提前把本地列表显示为已读，而是保留状态并提示错误。

### 安全

- Chrome 权限、全站内容脚本范围和设备令牌 Scope 均未扩大。
- 扩展仍不读取密码、MFA、网页登录 Cookie、iCloud Cookie、应用专用密码、网页 URL、
  页面正文、Cookie 或表单原有值。
- 继续使用 Manifest V3、自包含代码、PKCE 一次性授权码和可撤销的最小权限设备令牌。

### 兼容性

- 需要 Chrome 120 或更高版本。
- 兼容 OmniMail Web/API `0.3.4` 或更高版本，建议配合最新 Web 版本使用。
