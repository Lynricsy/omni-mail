### 更新摘要

- Float 现在会自动发现用户已在 Web 连接的 Gmail 与 QQ 邮箱，并提供账号筛选、搜索、
  最近邮件列表和安全正文阅读。
- OmniMail、iCloud、Gmail 与 QQ 统一使用可扩展的来源选择器；单个来源故障不会阻断
  其他邮箱。
- 从 `0.3.x` 升级时明确提示一次只读授权升级，不会静默扩大旧设备令牌权限。

### 新增

- 新增固定白名单的来源适配器、统一账号/摘要/正文模型和并行来源发现。
- Gmail 与 QQ 支持全部账号或单账号筛选、300ms 防抖搜索、正文读取与本地已读反馈。
- 凭据失效的账号继续显示，并提供前往 Web 修复的入口；已索引邮件仍可读取。
- 附件邮件会提示前往完整网页端，本版本不申请附件 Scope。

### 改进

- 双来源横向 Tab 改为语义化 combobox/listbox，支持方向键、Enter、Escape、完整标签和
  可见焦点，适应后续更多邮箱来源。
- 来源、账号和正文请求均有过期响应保护；切换来源或搜索时旧请求不会覆盖当前画面。
- 扩展 smoke 脚本拆分来源夹具与宣传图生成，保持发布测试文件职责清晰。

### 安全

- Service Worker 只接受 `gmail` 与 `qq` 联合类型并映射到写死的 OmniMail API 路径，
  未知来源无法变成任意请求代理。
- 新 Scope 只允许账号列表、邮件列表和单封正文 GET；连接、同步、附件、身份、发信和
  删除继续拒绝。
- 第三方凭据仍只在用户选择的 OmniMail 实例中处理，不会提供给 Float。

### 兼容性

- 需要 Chrome 120 或更高版本。
- 需要 OmniMail Web/API `0.10.0` 或更高版本；旧 Web/API 会拒绝新增来源请求。

### 安装与升级

- 快速迭代阶段仅发布 GitHub Release ZIP，不上传 Chrome Web Store；商店版继续保持
  已有稳定版本。
- `0.3.x` 用户首次打开收件页会看到“升级授权”，确认后才读取已连接 Gmail/QQ。
- 开发者模式可下载本版本 ZIP，解压后覆盖加载。

### 测试

- 通过 TypeScript、Oxlint、设备 Scope 与适配器单元测试、Web 授权 Playwright E2E、
  扩展生产构建和真实 Chromium smoke test。
- Chromium 覆盖旧 Scope 启动、升级授权、OmniMail/iCloud/Gmail/QQ 来源切换、搜索、
  QQ 凭据错误保留、正文沙箱、主题和登录恢复。
